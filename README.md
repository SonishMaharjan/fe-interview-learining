# Stack Ledger — frontend interview study guide

Open `index.html` in any browser (double-click it). Everything is in that one file and it works offline,
except the web fonts, which load from Google Fonts when you are online.

- `content/` holds the source of every entry as Markdown (96 files), readable on its own or on GitHub.
- Progress ("Mark as learned"), level filters and the drill setting are saved in your browser.

Sections: 58 library entries for the project stack, Backend Hands-on: NestJS (fundamentals, CRUD API, WebSockets), Full-stack Next.js (fundamentals, full app with auth and interceptors, real-time, design patterns, performance diagnosis), Learn full-stack: Next.js + Payload + Postgres (beginner, from scratch to automated deploys, then launch: SEO, Search Console, email, privacy), Website: Next.js + Sanity (build from scratch, CI/CD, Vercel and AWS deploy), the Senior Playbook (frontend, backend, databases,
system design, delivery, behavioral), System Design & Architecture, and AWS for Solutions Architects (SAA-C03).
